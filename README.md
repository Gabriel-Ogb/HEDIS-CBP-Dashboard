# HEDIS Controlling High Blood Pressure (CBP) — End-to-End Measure & Dashboard

A portfolio project demonstrating an end-to-end HEDIS quality-measure pipeline:
synthetic data generation, a cloud SQL measure engine, independent Python validation,
and an interactive Tableau dashboard. Built to NCQA HEDIS **Measurement Year 2025**
specifications using synthetic patient data (no real PHI).

**🔗 Live dashboard:** [View on Tableau Public](https://public.tableau.com/app/profile/gabriel.ogb/viz/HEDIS-CBP-Dashboard/Dashboard1)

---

## What this project does

Implements the HEDIS **Controlling High Blood Pressure (CBP)** measure: the percentage of
members aged 18–85 with hypertension whose most recent blood pressure reading in the
measurement year was adequately controlled (<140/90 mm Hg).

**Headline result (synthetic population):** CBP rate of **65.2%** (266 controlled of 408
measured), consistent with real-world plan performance.

## Skills demonstrated

- **SQL (BigQuery):** denominator, numerator, exclusions, and reporting funnel built as
  staged views in a cloud data warehouse.
- **Python (pandas):** a fully independent re-implementation of the measure that reconciles
  to the SQL results to the integer — a QA/validation layer.
- **Tableau:** a six-panel interactive dashboard (KPI, stratified rates with a parameter-
  driven dimension switcher, identification funnel, exclusions breakdown, gaps-in-care
  worklist, and improvement-opportunity ranking).
- **HEDIS domain knowledge:** measure-faithful logic, documented adaptations to synthetic
  data, small-cell suppression, and dual-threshold (systolic/diastolic) control logic.

## Pipeline

1. **Data** — synthetic patients generated with [Synthea](https://github.com/synthetichealth/synthea)
   (MITRE), anchored to MY 2025. *Raw data is not committed (size); regenerate with the
   command in `docs/01_synthea_setup.md`.*
2. **Measure engine** — `sql/` builds the denominator and the numerator/exclusions/funnel
   in BigQuery.
3. **Validation** — `python/validate_cbp.py` independently recomputes every stage in pandas
   and asserts a match against BigQuery (all checks pass).
4. **Dashboard** — `tableau/CBP_Dashboard_MY2025.twbx`, published to Tableau Public.

## Key results

| Metric | Value |
|---|---|
| Eligible denominator | 465 |
| Excluded (ESRD/transplant, pregnancy) | 57 |
| Measured population | 408 |
| Numerator (controlled) | 266 |
| **CBP rate** | **65.2%** |

Rate improves with age (58.5% → 62.4% → 75.2%); a ~7-point Hispanic/non-Hispanic disparity
was identified. See `docs/04_methodology_readme.md` for full methodology, documented
adaptations, and the SQL-vs-pandas reconciliation.

## Important notes

- **Synthetic data only** — generated by Synthea; contains no real patient information.
- Built to HEDIS MY 2025 specifications. Certain rules are simplified for synthetic data and
  **explicitly documented** (e.g., continuous-enrollment, the "two diagnoses" adaptation,
  small-cell suppression at n<20). HEDIS® is a registered trademark of NCQA.
